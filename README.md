One entry for make.fun's "Six Words, One Story" bounty: a complete little
story in exactly six words — a domestic twist about something sold and
something kept. `main.py` writes the six-word story to `entry.txt`
(`MAKEFUN_OUTPUT_DIR`, default `/output`). Deterministic, no network, no
model calls.

Run it:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
